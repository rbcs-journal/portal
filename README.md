# 🌐 RBCS Portal — Website Oficial da Revista

Este repositório contém o portal oficial da **Revista Brasileira de Computação e Software Científico (RBCS)**.

O site apresenta:
* O catálogo de artigos e softwares publicados com busca em tempo real.
* As 4 trilhas editoriais especializadas (Bioinformática, Computação Biomédica, IA e Computação Geral).
* O fluxo editorial passo a passo e link direto para novas submissões.
* As políticas de acesso aberto diamante e licenças OSI.

---

## 🚀 Publicação Automática

Este repositório possui uma GitHub Action (`.github/workflows/deploy-pages.yml`) configurada para fazer o deploy automático no **GitHub Pages**:
- URL: `https://rbcs-journal.github.io/portal/`

Para habilitar no repositório:
1. Vá em **Settings > Pages**.
2. Em **Source**, selecione **GitHub Actions**.
